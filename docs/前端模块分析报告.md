# 财务流水看板 - 前端模块分析报告

## 一、模块总览

### 1.1 项目架构

本项目是一个基于 Vue 3 + TypeScript 的财务流水看板应用，采用单页面应用（SPA）架构，使用 Vite 作为构建工具。

### 1.2 核心模块清单

| 模块名称 | 文件路径 | 模块类型 | 功能描述 |
|---------|---------|---------|---------|
| App | src/App.vue | 根组件 | 应用主容器，协调各模块 |
| TransactionForm | src/components/TransactionForm.vue | 功能组件 | 收支记录表单（新增/编辑） |
| TransactionTimeline | src/components/TransactionTimeline.vue | 展示组件 | 流水时间轴展示 |
| SummaryPanel | src/components/SummaryPanel.vue | 展示组件 | 月度统计概览 |
| BudgetPanel | src/components/BudgetPanel.vue | 功能组件 | 预算管理与设置 |
| SearchPanel | src/components/SearchPanel.vue | 功能组件 | 智能搜索与筛选 |
| Storage | src/utils/storage.ts | 工具模块 | 数据持久化与计算 |
| Types | src/types/index.ts | 类型定义 | 全局类型与常量 |

### 1.3 技术栈

- **框架**: Vue 3.4.0 (Composition API)
- **语言**: TypeScript 5.3
- **构建工具**: Vite 5.0
- **状态管理**: Vue 3 原生响应式 (ref, computed)
- **数据存储**: LocalStorage

## 三、模块流程详情

### 3.1 App.vue - 应用主容器

#### 3.1.1 模块概述

App.vue 是整个应用的根组件，负责：
- 全局状态管理（transactions, budgets, currentMonth）
- 子组件协调与事件处理
- 模态框控制
- 月份导航

#### 3.1.2 状态定义

| 状态名称 | 类型 | 初始值 | 说明 |
|---------|------|-------|------|
| transactions | Ref<Transaction[]> | [] | 所有流水记录 |
| budgets | Ref<Budget[]> | [] | 所有预算设置 |
| showForm | Ref<boolean> | false | 表单弹窗显示状态 |
| showSearch | Ref<boolean> | false | 搜索弹窗显示状态 |
| activeTab | Ref<'summary' \| 'budget'> | 'summary' | 侧边栏当前标签 |
| editingTransaction | Ref<Transaction \| null> | null | 当前编辑的记录 |
| currentMonth | Ref<string> | 当前年月 | 当前显示的月份 |

#### 3.1.3 计算属性

| 计算属性 | 依赖 | 返回值 | 说明 |
|---------|------|-------|------|
| dailySummaries | transactions, currentMonth | DailySummary[] | 按日期分组的流水 |
| monthlySummary | transactions, currentMonth | MonthlySummary | 月度收支汇总 |
| budgetStatuses | transactions, budgets, currentMonth | BudgetStatus[] | 预算执行状态 |

#### 3.1.4 事件处理流程

```
┌─────────────────────────────────────────────────────────────┐
│                    App.vue 事件处理                          │
├─────────────────────────────────────────────────────────────┤
│                                                             │

│  ─────────────────                                          │
│  点击"新增记录" → handleAddNew()                            │
```

### 3.2 TransactionForm - 收支记录表单

#### 3.2.1 模块概述

用于新增和编辑收支记录的表单组件，以模态框形式展示。

#### 3.2.2 Props

| 属性名 | 类型 | 必填 | 说明 |
|-------|------|------|------|
| editTransaction | Transaction \| null | 否 | 编辑模式时传入的数据 |

#### 3.2.3 Emits

| 事件名 | 参数 | 说明 |
|-------|------|------|
| submit | Transaction | 表单提交，返回记录数据 |
| cancel | - | 取消操作 |

#### 3.2.4 内部状态

| 状态名 | 类型 | 初始值 | 说明 |
|-------|------|-------|------|
| type | Ref<TransactionType> | 'expense' | 收支类型 |
| amount | Ref<number> | 0 | 金额 |
| category | Ref<Category> | 'catering' | 类别 |
| date | Ref<string> | 今天 | 日期 |
| note | Ref<string> | '' | 备注 |

#### 3.2.5 交互流程

```
┌─────────────────────────────────────────────────────────────┐
│                 TransactionForm 交互流程                     │
├─────────────────────────────────────────────────────────────┤
│                                                             │
│  初始化流程                                                 │
│  ─────────────────                                          │
│  watch editTransaction                                       │
│     ├── 有值（编辑模式）                                     │
│     │   └── 回填所有字段                                    │
│     └── 无值（新增模式）                                     │
│         └── resetForm() → 重置为默认值                      │
│                                                             │
│  类型切换流程                                               │
│  ─────────────────                                          │
│  点击"支出/收入"标签                                         │
│     └── 更新 type                                           │
│     └── watch type 触发                                     │
│     └── category 重置为该类型第一个选项                      │
│     └── categories 计算属性重新计算                          │
│                                                             │
│  类别选择流程                                               │
│  ─────────────────                                          │
│  点击类别按钮                                                │
│     └── 更新 category                                       │
│     └── 按钮高亮状态更新                                     │
│                                                             │
│  提交表单流程                                               │
│  ─────────────────                                          │
│  点击"添加/保存"                                            │
│     ├── 验证 amount > 0                                     │
│     ├── 验证失败 → alert('请输入有效金额')                   │
│     ├── 验证成功                                            │
│     │   ├── 构建 Transaction 对象                           │
│     │   │   ├── id: 编辑用原ID，新增用 generateId()         │
│     │   │   ├── createdAt: 编辑用原值，新增用 Date.now()    │
│     │   │   └── 其他字段取表单值                            │

│     └── resetForm()                                         │
│                                                             │
│  取消流程                                                   │
│  ─────────────────                                          │
│  点击"取消"                                                 │

│                                                             │
└─────────────────────────────────────────────────────────────┘
```

#### 3.2.6 表单字段详情

| 字段 | 组件类型 | 验证规则 | 选项值 |
|------|---------|---------|--------|
| 类型 | 标签切换按钮 | 必填 | 支出、收入 |
| 金额 | 数字输入框 | > 0 | - |
| 类别 | 网格按钮组 | 必填 | 支出：餐饮、交通、购物、娱乐、其他<br>收入：工资、理财、奖金、其他 |
| 日期 | 日期选择器 | 必填 | 默认今天 |
| 备注 | 文本输入框 | 可选，最大100字符 | - |

### 3.3 TransactionTimeline - 流水时间轴

#### 3.3.1 模块概述

以时间轴形式展示每日的收支流水，支持编辑和删除操作。

#### 3.3.2 Props

| 属性名 | 类型 | 说明 |
|-------|------|------|
| dailySummaries | DailySummary[] | 按日期分组的流水数据 |

#### 3.3.3 Emits

| 事件名 | 参数 | 说明 |
|-------|------|------|
| edit | Transaction | 点击编辑按钮 |
| delete | string (id) | 点击删除按钮 |

#### 3.3.4 展示逻辑

```
┌─────────────────────────────────────────────────────────────┐
│               TransactionTimeline 展示逻辑                   │
├─────────────────────────────────────────────────────────────┤
│                                                             │
│  空状态展示                                                 │
│  ─────────────────                                          │
│  dailySummaries.length === 0                               │
│     └── 显示空状态图标 📊                                   │
│     └── 提示文字："暂无记录"                                │
│     └── 引导文字："点击右上角'新增记录'开始记账"            │
│                                                             │
│  时间轴展示                                                 │
│  ─────────────────                                          │
│  v-for day in dailySummaries                               │
│     ├── 日期头部 (day-header)                               │
│     │   ├── 日期：formatDate(day.date)                     │
│     │   └── 当日汇总                                        │
│     │       ├── 收入：+¥day.income                         │
│     │       └── 支出：-¥day.expense                        │
│     │                                                       │
│     └── 交易列表 (transaction-list)                         │
│         v-for transaction in day.transactions              │
│             ├── 图标：CATEGORY_ICONS[category]             │
│             ├── 类别：CATEGORY_LABELS[category]            │
│             ├── 备注：note（如有）                          │
│             ├── 金额：±¥amount（收入绿色/支出红色）         │
│             └── 操作按钮（悬停显示）                         │
│                 ├── 编辑按钮 → emit('edit')                │
│                 └── 删除按钮 → handleDelete()              │
│                                                             │
└─────────────────────────────────────────────────────────────┘
```

#### 3.3.5 删除确认流程

```
点击删除按钮
    └── confirm('确定要删除这条记录吗？')
        ├── 确认 → emit('delete', transaction.id)
        └── 取消 → 无操作
```

### 3.5 BudgetPanel - 预算管理面板

#### 3.5.1 模块概述

管理各支出类别的月度预算，展示预算执行进度和预警。

#### 3.5.2 Props

| 属性名 | 类型 | 说明 |
|-------|------|------|
| budgetStatuses | BudgetStatus[] | 各类别预算状态 |
| currentMonth | string | 当前月份 |

#### 3.5.3 Emits

| 事件名 | 参数 | 说明 |
|-------|------|------|
| updateBudget | Budget | 更新预算设置 |

#### 3.5.4 预算状态计算

```
┌─────────────────────────────────────────────────────────────┐
│                   预算状态计算逻辑                           │
├─────────────────────────────────────────────────────────────┤
│                                                             │
│  遍历所有支出类别 (EXPENSE_CATEGORIES)                       │
│     ├── 获取该类别预算（budget）                            │
│     ├── 计算该类别支出（spent）                             │
│     ├── 计算剩余（remaining = budget - spent）              │
│     ├── 计算百分比（percentage = spent / budget * 100）     │
│     └── 确定预警级别（warningLevel）                        │
│         ├── percentage >= 100% → 'danger'（红色）          │
│         ├── percentage >= 80%  → 'warning'（橙色）         │
│         └── 其他               → 'none'（绿色）            │
│                                                             │
└─────────────────────────────────────────────────────────────┘
```

#### 3.5.5 交互流程

```
┌─────────────────────────────────────────────────────────────┐
│                  BudgetPanel 交互流程                        │
├─────────────────────────────────────────────────────────────┤
```

### 3.8 Types - 类型定义模块

#### 3.8.1 核心类型

```typescript
// 交易记录
interface Transaction {
  id: string           // 唯一标识
  type: 'income' | 'expense'  // 类型
  amount: number       // 金额
  category: Category   // 类别
  date: string         // 日期 (YYYY-MM-DD)
  note: string         // 备注
  createdAt: number    // 创建时间戳
}

// 每日汇总
interface DailySummary {
  date: string
  income: number
  expense: number
  transactions: Transaction[]
}

// 月度汇总
interface MonthlySummary {
  totalIncome: number
  totalExpense: number
  balance: number
  categoryBreakdown: Record<string, number>
}

// 预算
interface Budget {
  category: ExpenseCategory
  limit: number
  month: string
}

interface BudgetStatus {
  category: ExpenseCategory
  label: string
  icon: string
  budget: number
  spent: number
  remaining: number
  percentage: number
  warningLevel: 'none' | 'warning' | 'danger'
}
```

## 六、总结

### 6.1 模块职责划分

| 层级 | 模块 | 职责 |
|------|------|------|
| 应用层 | App.vue | 全局状态管理、组件协调 |
| 功能层 | TransactionForm, BudgetPanel, SearchPanel | 业务功能实现 |
| 展示层 | TransactionTimeline, SummaryPanel | 数据展示渲染 |
| 数据层 | storage.ts | 数据持久化、计算逻辑 |
| 定义层 | types.ts | 类型定义、常量配置 |

### 6.2 核心交互路径

1. **记账流程**: 点击新增 → 填写表单 → 提交 → 保存 → 列表更新
2. **编辑流程**: 点击编辑 → 回填数据 → 修改 → 保存 → 列表更新
3. **删除流程**: 点击删除 → 确认 → 删除 → 列表更新
4. **查询流程**: 点击搜索 → 设置条件 → 搜索 → 展示结果
5. **预算流程**: 切换预算标签 → 设置预算 → 保存 → 进度更新

### 6.3 技术特点

- 采用 Vue 3 Composition API，逻辑清晰
- 计算属性实现数据联动，自动更新
- LocalStorage 实现离线数据持久化
- 组件化设计，职责单一，易于维护
