# 财务流水看板 - 项目分析报告

## 一、项目概述

### 1.1 项目信息
- **项目名称**: finance-dashboard（财务流水看板）
- **技术栈**: Vue 3 + TypeScript + Vite
- **版本**: 0.0.0
- **数据存储**: LocalStorage

### 1.2 项目功能
一个轻量级的个人财务管理应用，支持：
- 收支记录的增删改查
- 月度统计与类别分布
- 预算管理与超支预警
- 智能搜索与筛选

## 四、模块流程详情

### 4.1 App.vue - 根组件

#### 4.1.1 状态管理

| 状态变量 | 类型 | 初始值 | 说明 |
|---------|------|-------|------|
| transactions | `Transaction[]` | `[]` | 所有交易记录 |
| budgets | `Budget[]` | `[]` | 所有预算设置 |
| showForm | `boolean` | `false` | 表单弹窗显示状态 |
| showSearch | `boolean` | `false` | 搜索弹窗显示状态 |
| activeTab | `'summary' \| 'budget'` | `'summary'` | 当前激活的标签页 |
| editingTransaction | `Transaction \| null` | `null` | 当前编辑的交易 |
| currentMonth | `string` | 当前月份 | 当前选中的月份 |

#### 4.1.2 计算属性

| 计算属性 | 依赖 | 返回值 | 说明 |
|---------|------|-------|------|
| dailySummaries | transactions, currentMonth | `DailySummary[]` | 按日期分组的交易汇总 |
| monthlySummary | transactions, currentMonth | `MonthlySummary` | 月度统计数据 |
| budgetStatuses | transactions, budgets, currentMonth | `BudgetStatus[]` | 预算状态列表 |

#### 4.1.3 事件处理流程

**新增记录流程**:
```
用户点击"新增记录"按钮
       │
       ▼
handleAddNew()
       │
       ├── editingTransaction = null
       │
       └── showForm = true
              │
              ▼
       TransactionForm 显示（新增模式）
```

**编辑记录流程**:
```
用户点击交易项的编辑按钮
       │
       ▼
handleEdit(transaction)
       │
       ├── editingTransaction = transaction
       │
       └── showForm = true
              │
              ▼
       TransactionForm 显示（编辑模式）
```

**提交记录流程**:
```
TransactionForm emit('submit', transaction)
       │
       ▼
handleSubmit(transaction)
       │
       ├── 查找是否存在相同ID的记录
       │   ├── 存在: 更新记录
       │   └── 不存在: 添加新记录
       │
       ├── saveTransactions() → LocalStorage
       │
       ├── showForm = false
       │
       └── editingTransaction = null
```

**删除记录流程**:
```
用户点击交易项的删除按钮
       │
       ▼
TransactionTimeline emit('delete', id)
       │
       ▼
handleDelete(id)
       │
       ├── 过滤删除指定ID的记录
       │
       └── saveTransactions() → LocalStorage
```

**月份导航流程**:
```
用户点击月份导航按钮
       │
       ├── 上月: prevMonth()
       │         └── currentMonth = 上一个月
       │
       ├── 下月: nextMonth()
       │         └── currentMonth = 下一个月
       │
       └── 今天: goToToday()
                 └── currentMonth = 当前月份
```

#### 4.6.5 搜索逻辑

搜索函数 `searchTransactions()` 按以下顺序过滤：

1. **日期范围过滤**
   - `thisWeek`: 本周一至周日
   - `thisMonth`: 本月第一天至最后一天
   - `custom`: 自定义开始和结束日期

2. **类型过滤**
   - 按收入/支出类型筛选

3. **类别过滤**
   - 按交易类别筛选

4. **金额范围过滤**
   - 最小金额 ≤ 交易金额 ≤ 最大金额

5. **关键词过滤**
   - 匹配备注或类别名称（不区分大小写）

6. **排序**
   - 按日期降序
   - 同日期按创建时间降序

## 十一、总结

本项目是一个功能完整的个人财务管理应用，采用 Vue 3 Composition API 和 TypeScript 开发。项目结构清晰，模块划分合理，数据流单向可控。主要特点包括：

1. **模块化设计**: 6 个核心组件各司其职，通过 Props 和 Emits 进行通信

3. **本地存储**: 数据持久化到 LocalStorage，无需后端服务
4. **用户体验**: 提供预算预警、智能搜索等增强功能
5. **类型安全**: 完整的 TypeScript 类型定义，减少运行时错误
